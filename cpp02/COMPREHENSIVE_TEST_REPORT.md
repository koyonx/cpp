## 2. コードの改善

### 2.1 friendキーワードの削除
**問題点**: Subjectではfriendキーワードの使用が禁止（-42点のペナルティ）

**修正箇所**:
- ex01/Fixed.hpp: operator<<のfriend宣言を削除
- ex02/Fixed.hpp: operator<<のfriend宣言を削除
- ex03/Fixed.hpp: operator<<のfriend宣言を削除
- ex03/Point.hpp: operator<<のfriend宣言を削除

**代替手段**:
- クラス外部でoperator<<を宣言
- 公開メソッド（toFloat()、getX()、getY()等）を使用してアクセス

### 2.2 Orthodox Canonical Form準拠

**ex03/Point.hpp**:
- Pointクラスのメンバ変数がconst（x、y）
- コピー代入演算子を実装不可能な状態だった
- **解決策**: コピー代入演算子をprivateで宣言し、使用を禁止

```cpp
private:
    Point& operator=(const Point& other);  // 使用禁止だが存在
```
